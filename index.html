Sertifikasi: UL, CE, FM Approved

  1. Perencanaan dan Desain Sistem

    Buat layout bangunan, tentukan zona-zona, dan hitung jumlah perangkat yang diperlukan sesuai standar NFPA atau SNI.

  2. Instalasi Control Panel

    Pasang panel kontrol di lokasi yang aman, mudah diakses, dan terlindung dari kelembaban. Hubungkan ke sumber listrik utama dan backup.

  3. Pemasangan Kabel dan Wiring

    Pasang kabel sesuai diagram wiring. Pastikan koneksi ground yang baik dan gunakan kabel fire-rated untuk keselamatan.

  4. Instalasi Detektor dan Perangkat

    Pasang smoke detector di langit-langit, heat detector di area berisiko tinggi, dan manual call point di pintu keluar.

  5. Pemasangan Sounder dan Alarm

    Pasang sounder di area strategis dengan jarak yang sesuai untuk memastikan audibilitas minimal 65dB.

  6. Konfigurasi dan Setting Panel

    Program zona-zona, set sensitivitas detektor, konfigurasikan delay time, dan atur parameter alarm.

  7. Testing dan Commissioning

    Lakukan pengujian fungsi setiap komponen, simulasi alarm, dan verifikasi keseluruhan sistem.

Parameter Dasar
  • Zone Configuration: Atur jumlah zona sesuai layout bangunan
  • Detector Sensitivity: Set sensitivitas berdasarkan jenis area (normal/high sensitivity)
  • Alarm Delay: Konfigurasikan waktu delay untuk menghindari false alarm
  • Sounder Pattern: Atur pola suara alarm (continuous/pulse)
Advanced Settings
  • Day/Night Mode: Aktifkan mode berbeda untuk siang/malam
  • Silence Function: Konfigurasikan tombol silence untuk reset alarm
  • Supervisory Monitoring: Aktifkan monitoring kondisi perangkat
  • Network Integration: Setup koneksi dengan sistem BMS jika diperlukan
Penting: Semua setting harus sesuai dengan regulasi keamanan kebakaran setempat dan manual pabrikan perangkat.

Prosedur Testing
Weekly Testing
  • Periksa indikator panel kontrol
  • Test fungsi manual call point
  • Verifikasi power supply backup
Monthly Testing
  • Simulasi alarm di setiap zona
  • Test sensitivitas detektor
  • Periksa kondisi kabel dan koneksi
Maintenance Rutin
  • Cleaning: Bersihkan detektor dari debu setiap 6 bulan
  • Battery Check: Periksa dan ganti baterai backup sesuai jadwal
  • Software Update: Update firmware panel jika tersedia
  • Documentation: Catat semua aktivitas maintenance dan testing
